# SpendSense 💸

> Know where your money goes.

SpendSense is a frontend web application that helps users understand and track their recurring subscription spending.

Many people subscribe to multiple OTT and digital services but may not regularly use all of them. SpendSense lets users manually enter their subscriptions, track monthly spending, identify potentially underused subscriptions, and understand the possible yearly impact.

---

## 🎯 Problem Statement

Recurring subscriptions can become difficult to track when users have several services running at the same time.

SpendSense provides a simple dashboard where users can:

- Add their subscriptions
- Track monthly spending
- Categorize subscriptions
- Record usage frequency
- Identify potentially unused spending
- View spending through charts
- Set a savings goal
- Monitor savings progress

---

## ✨ Features

### 📊 Spending Dashboard

The dashboard displays:

- Monthly spending
- Active subscriptions
- Potential unused spending
- Yearly spending impact
- Monthly spending trend
- Spending by category

### ➕ Subscription Manager

Users can add subscriptions with:

- Service name
- Monthly price
- Category
- Usage frequency

Subscriptions can also be removed or cleared.

### 🔎 Usage Filters

Subscriptions can be filtered by:

- All
- Frequently used
- Rarely used

### 💧 Leak Analysis

SpendSense analyzes subscription usage and highlights subscriptions that may represent potential spending leaks.

Users can see:

- Potential monthly leak
- Subscriptions to review
- Percentage of spending that may be leaking

### 🎯 Savings Goal

Users can set a savings goal and track their progress visually.

### 💡 SpendSense Insights

The dashboard provides simple insights based on the user's entered subscription data.

### 📩 Contact Form

Users can submit their name, email, and message through the contact section.

### 🌓 Dark / Light Mode

The interface supports dark and light themes, with the selected theme saved for future visits.

### 📱 Responsive Navigation

The navigation includes a mobile menu for smaller screens.

### 🎬 Scroll Animations

Sections reveal smoothly as the user scrolls through the page.
